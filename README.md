# Bias Detection in Language Models

Research project systematically testing LLMs for demographic bias.

## Methodology

- **Prompt Generation** - Template-based across demographics
- **Multiple Dimensions** - Gender, age, race
- **Bias Analysis** - Sentiment, word choice, stereotypes
- **Statistical Testing** - T-tests, ANOVA, effect sizes

## Features

- 300+ lines of experiment code
- Statistical significance testing
- Automated reporting
- Jupyter notebook analysis

## Quick Start

```bash
pip install -r requirements.txt
python examples/quick_test.py
```

## Key Findings

- Documented measurable bias patterns
- Quantified sentiment differences
- Published reproducible methodology

## What I Learned

- Systematic bias testing frameworks
- Statistical analysis of NLP outputs
- Ethical AI research practices
- Reproducible research methods
